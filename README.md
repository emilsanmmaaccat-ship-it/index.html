# Emil San V. Macatiag — Gardening Portfolio

A responsive single-page gardening portfolio website for **Emil San V. Macatiag**. The site presents a gardening-focused personal profile, skills, selected garden projects, and contact information.

## 🌱 Overview

This portfolio is designed with a clean, nature-inspired visual style using green, sage, cream, sand, and brown tones. It uses a fixed navigation bar, responsive layouts, project cards, and a mobile navigation menu.

The page title is **"Emil San V. Macatiag | Gardening Portfolio"**.

## 📱 Responsive Design

The website includes a responsive breakpoint at **768px**.

On smaller screens:

- The desktop navigation links are hidden.
- A hamburger menu button appears.
- The navigation becomes a vertical menu.
- About, services, and project grids change to a single-column layout.
- The hero content is centered.
- Buttons are centered and wrapped when necessary.

## 🖼️ Customization

You can personalize the portfolio by editing `index.html`.

### Change the Name

Search for:

```html
Emil San V. Macatiag
```

and replace it with the desired name.

### Change the Email

Replace:

```text
your-email@example.com
```

with the actual email address.

Also update the `mailto:` link:

```html
<a href="mailto:your-email@example.com">
```

### Change Images

The website currently uses Unsplash image URLs for the hero, About section, and project cards. Replace those URLs with your own image URLs if you want to use personal gardening photos.

### Add Projects

Duplicate a project card inside the `.projects-grid` section and update:

- Project image
- Project title
- Project description
- Project link
